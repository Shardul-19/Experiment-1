## **Aim**

To study and implement basic Python programming concepts such as data types, type checking, arithmetic operations, user input, mathematical functions, and conditional statements.

## **Theory**

Python is a high-level, interpreted programming language that supports multiple data types and provides built-in functions for mathematical and logical operations.

In this experiment, the following concepts are demonstrated:

1. **Multiple Variable Assignment**
   Python allows assigning values of different data types to multiple variables in a single statement.

2. **Data Types and `type()` Function**
   The `type()` function is used to identify the data type of a variable such as `int`, `float`, `str`, and `bool`.

3. **Arithmetic Operations**
   Basic arithmetic operations like addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`), and exponentiation (`**`) are performed using both predefined values and user input.

4. **User Input**
   The `input()` function is used to take input from the user. The input is converted into integers or floats using `int()` and `float()`.

5. **Math Module**
   The `math` module provides mathematical constants and functions such as:

   * `math.pi` for calculating the area of a circle
   * `math.log10()` for finding logarithmic values

6. **Conditional Statements**
   The `if-else` statement is used to compare two numbers and determine which one is greater.
This experiment helps in understanding how Python handles calculations, conditions, and built-in libraries.

---
## **Conclusion**

Thus, the experiment successfully demonstrates fundamental Python programming concepts including variable assignment, data types, arithmetic calculations, user input handling, use of the math module, and decision-making using conditional statements. This experiment builds a strong foundation for further Python programming.
